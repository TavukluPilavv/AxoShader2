# AxoShader2

Minecraft Java 1.21.1 için Iris shader pack geliştirme deposu.

## Hedeflenen görünüm
- Videodaki gibi doğal/gerçekçi gökyüzü, bulutlar ve parlak güneş
- Yeryüzüne vuran sıcak güneş ışığı
- Ağaç, yaprak, oyuncu ve mob gölgeleri
- Rüzgârda sallanan yapraklar
- Hareketli ve daha gerçekçi su
- FPS odaklı Lite / Balanced / High seçenekleri

## Kurulum
1. Minecraft Java 1.21.1 için Iris kur.
2. GitHub Actions'tan `AxoShader2` ZIP artifact'ini indir.
3. ZIP'i `.minecraft/shaderpacks` içine koy.
4. Iris Shader Packs menüsünden seç.

## Durum
Bu, boş shader dosyaları yerine temel sahne render'ı olan geliştirme başlangıcıdır. Minecraft/Iris içinde henüz test edilmedi. Gerçekçi volumetrik bulutlar, güneş ışınları, tam gölge ve yaprak animasyonları henüz geliştirme aşamasındadır. Önce shader'ın düzgün yüklenip dünyayı çizdiği doğrulanmalı.
